## 💻 Projetos

### Simulador de Empréstimos
Calculadora desenvolvida em Portugol para simular empréstimos utilizando juros compostos e o sistema de amortização Tabela Price.

Funcionalidades:
- Informar o valor do empréstimo.
- Definir a quantidade de parcelas.
- Calcular o valor das prestações.
- Calcular o montante total.
- Exibir uma tabela de amortização.

## 🛠️ Tecnologias utilizadas

- Portugol Studio

## 🎯 Objetivo

Praticar e desenvolver minha lógica de programação, fortalecendo os conhecimentos fundamentais que serão utilizados futuramente no desenvolvimento de software.
